# Punto 12 — DHCP en router1

## Requisito
Configurar en `router1` un servidor DHCP con `dnsmasq` que:

- atienda solo la red1 (`192.168.148.0/23`)
- entregue una IP fija a `Workstation 1`
- entregue máscara de subred, gateway y DNS interno (router4)

## Pasos

1. Instalar dnsmasq en `router1`:

```bash
sudo apt update
sudo apt install -y dnsmasq
```

2. La interfaz de `router1` conectada a Red1 es `eth0`.

3. Obtener la MAC de Workstation 1:

```bash
ip link show
```

4. Editar `/etc/dnsmasq.conf` en `router1` y configurar:

```ini
# No actuar como servidor DNS (DNS ya lo atiende router4)
port=0

# No leer /etc/resolv.conf
no-resolv

# Escuchar solo en la interfaz de Red1
interface=eth0

# === DHCP para Red1: 192.168.148.0/23 ===
dhcp-range=192.168.148.10,192.168.149.200,255.255.254.0,12h

# Puerta de enlace por defecto
dhcp-option=option:router,192.168.148.1

# Servidor DNS interno (router4)
dhcp-option=option:dns-server,192.168.152.1

# Máscara de subred
dhcp-option=option:netmask,255.255.254.0

# IP fija para Workstation 1
dhcp-host=00:16:3e:d4:6e:23,ws1,192.168.148.22,infinite
```

5. Reiniciar el servicio `dnsmasq`:

```bash
sudo systemctl restart dnsmasq
sudo systemctl status dnsmasq
```

## Datos que recibirá Workstation 1

- IP: `192.168.148.22`
- Máscara: `255.255.254.0`
- Gateway: `192.168.148.1`
- DNS: `192.168.152.1`

## Nota
Asegúrate de remplazar:

- `eth0` debe ser la interfaz real de `router1` en Red1
- `00:16:3e:d4:6e:23` es la MAC real de `Workstation 1`


## Verificación

1. En `router1`, confirmar que `dnsmasq` está activo:

```bash
sudo systemctl status dnsmasq
```

2. En `router1`, verificar que escucha en `eth0`:

```bash
sudo ss -tulnp | grep dnsmasq
```

3. En `Workstation 1`, renovar la dirección DHCP si ya tenía una anterior:

```bash
sudo dhclient -r && sudo dhclient
```

4. En `Workstation 1`, comprobar la dirección IP asignada:

```bash
ip a
```

Debe aparecer `192.168.148.22` en la interfaz de red.

5. Desde `Workstation 1`, verificar conectividad con el gateway:

```bash
ping -c 3 192.168.148.1
```

6. Desde `Workstation 1`, verificar resolución DNS a través de `router4`:

```bash
ping -c 3 router1.redes.cs.intra
```

Si responde correctamente, entonces DHCP y DNS están funcionando.
